# Reporting pédagogique — données LAB uniquement

Les fichiers du dossier sont des gabarits ou des instantanés **du dépôt privé de test**.

- `weekly-template.md` : point hebdomadaire démonstratif.
- `delta-log.csv` : écarts entre instructions et résultat réel, pas de reconstruction fictive.
- `demo-status.md` (produit par CI) : exemple utilisant le jeu de données fictif.
- `lab-current.md` (artefact Actions déclenché manuellement) : chiffres réels **du LAB**, pas du projet officiel.

La progression = livrables validés selon critères définis ; elle ne peut pas se déduire du nombre de commits. Les heures et ETC nécessitent la déclaration des contributeurs.
