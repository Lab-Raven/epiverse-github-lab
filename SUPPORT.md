# Support du laboratoire

- Problème de configuration GitHub → ouvrir une Issue `[LAB][INCIDENT]` ou `[LAB][BUG]`.
- Question de procédure → utiliser les Discussions lorsqu'elles sont activées.
- Incident de confidentialité / secret → contacter directement la propriétaire du dépôt, sans publication de preuve sensible.
- Ne pas créer de ticket sur le dépôt de l'équipe pour un test de ce laboratoire.
- Dépannage Actions : Issue #7.
