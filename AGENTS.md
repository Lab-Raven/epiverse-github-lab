# Règles agents — GitHub LAB public

Le dépôt `Lab-Raven/epiverse-github-lab` est un laboratoire **PUBLIC**, non officiel et utilisant exclusivement des données fictives.

## Périmètre
- Ne jamais modifier, cloner ou publier depuis `epiverse-epitech/epiverse`.
- Ne pas introduire d'identités réelles, de credentials, de logs sensibles, de documents privés ou de détails confidentiels du projet.
- Les Issues, PRs, Wiki et Pages sont publics ; le Project n°1 est privé mais ne masque pas les Issues liées.
- Ne pas activer de ressources facturables, inviter des membres, modifier les permissions ou publier de packages sans accord humain.
- Les déploiements GitHub Pages sont uniquement manuels et destinés à une maquette statique fictive.

## Processus
1. Lire `README.md`, `CONTRIBUTING.md` et `SECURITY.md`.
2. Utiliser une branche LAB et une PR liée à une Issue fictive.
3. Exécuter les tests Python, scripts Bash, sécurité et scanner heuristique de publication.
4. Effectuer une revue humaine du diff et des données avant merge.
5. Distinguer clairement conçu, préparé, testé, validé et publié.

## Sécurité
Les scanners ne garantissent pas l'absence de fuite. Aucun `git push --force` ou réécriture de l'historique sans autorisation explicite. Aucun déploiement de code réel.
