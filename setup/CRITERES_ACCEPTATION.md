# Recette du laboratoire — critères de succès

- [ ] Dépôt PRIVATE, cible officielle inchangée.
- [ ] README, TEAM, RACI, DoD, risques et ADR navigables.
- [ ] Templates GitHub Issue fonctionnels.
- [ ] Issues de démonstration créées, jamais confondues avec le backlog réel.
- [ ] Project privé, champs et vues Portfolio/Board/Sprint/Roadmap/Risques/Pédagogie configurés et vérifiés.
- [ ] PR liée à une Issue avec template et revue lorsque possible.
- [ ] GitHub Actions CI réussie (logs) et reporting téléchargeable.
- [ ] Aucune donnée fictive utilisée pour annoncer un avancement réel.
- [ ] CODEOWNERS et Dependabot compris et actifs.
- [ ] Discussions/Wiki/Security/Releases/Packages/Insights examinés, limitations notées.
- [ ] RACI et comptes GitHub validés avant tout portage.
- [ ] Démonstration pédago : Issue → PR → Tests → Preuve → Livrable.
- [ ] Feuille de transfert et procédure de retour arrière approuvées.
- [ ] Accord écrit avant toute action sur `epiverse-epitech/epiverse`.
