# Procédure de transfert vers le dépôt officiel — INTERDITE SANS ACCORD

1. Demander validation écrite explicite d'Estelle sur le périmètre exact et la date de transfert.
2. Confirmer équipe actuelle, rôle, compte GitHub et permissions.
3. Auditer l'existant de `epiverse-epitech/epiverse` : branches, workflows, CI, releases, tickets, sécurité et équipes.
4. Dédupliquer les Issues existantes et le Jira/Notion ; migrer **sélectivement**.
5. Ouvrir une branche spécifique dans le dépôt officiel ; proposer une PR, jamais de push direct sur main/develop.
6. Comparer les changements et les résultats CI, demander revue et accord avant merge.
7. Conserver les liens source et les IDs, ne jamais fabriquer de métriques rétroactives.
8. Préparer le rollback et vérifier la confidentialité de toute documentation publiée.
9. Ne pas copier les workflows LAB qui décrivent des données fictives, ni aucun secret.
