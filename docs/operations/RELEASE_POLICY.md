# Releases, Pages et packages — LAB public

- Aucune release de l'application EpiVerse réelle ne provient de ce dépôt.
- Les versions `v0.0.N-lab` sont exclusivement des archives ou brouillons de démonstration.
- Les **draft releases** sont à valider avant publication. Une release publiée et ses assets peuvent devenir publics.
- GitHub Pages est préparé dans `docs/site`, mais le déploiement est **manuel**, après activation de Pages → GitHub Actions.
- Les images de test Docker ne contiennent aucun code produit. GHCR peut avoir une visibilité différente de celle du dépôt et des coûts propres.
- Une release de démonstration doit référencer commit, tests CI, Issue, PR et statut d'acceptation.
- Ne pas publier automatiquement secrets, domaines, données de l'équipe ni produits fonctionnels.
