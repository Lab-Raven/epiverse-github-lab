# Vues Projects — configuration de démonstration

Après création du Project d'organisation **PRIVATE**, constituer les vues suivantes :

1. **Portfolio global** — Table, toutes les Issues, WBS, priorité, responsable, date et charge.
2. **Kanban** — Board, par Status.
3. **Sprint actif** — Board ou Table, filtré par Iteration.
4. **Roadmap** — Dates de début et de cible, jalons et dépendances.
5. **Par domaine** — Workstream (Frontend, Backend, Campus 2,5D, Data, IA, Infra, Sécurité, QA, Gouvernance).
6. **Par personne** — groupement Assignees ; les membres non confirmés restent sans assignation.
7. **Risques et décisions** — Type=Risk/Decision ; probabilité et impact dans l'Issue.
8. **Qualité / tests** — Status=Review/Testing/Blocked, liens PR et CI.
9. **Livraisons et preuves** — Validation=Accepted, lien Evidence, Requirement ID et WBS.
10. **Pilotage pédagogique** — taux de couverture **uniquement sur critères définis**, charge Actual/ETC, Delta Log, rétrospective.

Autorisations : seuls les administrateurs et contributeurs de test explicitement invités. Les champs et vues restent à configurer dans GitHub Projects v2, ce document seul ne les crée pas.
