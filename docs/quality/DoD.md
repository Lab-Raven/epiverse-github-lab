# Definition of Done — laboratoire

Une tâche n'est **acceptée** que si :
1. Exigence, ticket, owner et critères d'acceptation sont renseignés.
2. Code/document associé à une PR avec relecture lorsque possible.
3. Tests adaptés exécutés ; CI verte si applicable, résultats consignés.
4. Risques sécurité/confidentialité/accessibilité évalués si pertinents.
5. Documentation et artefacts maintenus.
6. Preuve reproductible et environnement indiqués.
7. Validation finale explicite, ou dérogation datée indiquant risque, owner et échéance.

Le statut GitHub "closed" ne prouve pas à lui seul la validation produit.
