# Exposition historique — point de contrôle

Le LAB a été privé puis rendu public et a comporté des noms réels de membres, des descriptions de missions et des interprétations de responsabilités non encore validées.

Les derniers fichiers de gouvernance ont été remplacés par des rôles **fictifs**, mais :
- les commits antérieurs, branches, PRs et fichiers Wiki historiques peuvent rester consultables ;
- les modifications de la dernière version n'effacent **pas** les contenus déjà exposés ;
- les copies, moteurs de recherche, forks et logs peuvent prolonger l'exposition ;
- les Issues publiques et leurs historiques d'édition doivent aussi être inspectés.

**Actions préalables à toute diffusion externe du LAB :** examiner l'historique Git, les PR et leurs patches, les Issues/commentaires, le Wiki, les rapports Actions, les releases/artefacts et les permissions ; établir si les données exigeaient confidentialité ou consentement ; documenter la remédiation. Si un secret a été exposé, il doit être révoqué immédiatement.

Ne pas effectuer de réécriture destructive d'historique ou de force-push sans autorisation distincte : cela casserait potentiellement les PR, releases et preuves. Les contrôles automatiques de la dernière révision ne constituent pas un audit rétroactif.
