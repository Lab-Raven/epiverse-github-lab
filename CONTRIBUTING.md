# Contribuer au laboratoire EpiVerse

**NON OFFICIEL — DÉPÔT PRIVÉ DE TEST.**

1. Créer une Issue précisant besoin, responsable (si confirmé), critères d'acceptation, estimation et preuve attendue.
2. Utiliser une branche `feature/LAB-<num>-sujet`, `fix/...`, `docs/...`.
3. Faire une pull request vers `main` avec `Closes #<num>`, tests, lien de preuve et checklist DoD.
4. Examiner les changements et attendre la CI. Un merge n'est pas une validation métier.
5. Documenter écarts, décisions et rétrospectives dans `reporting/` et `docs/adr/`.

**Interdictions :** secrets, données personnelles réelles, mirroring, publication Pages, déploiement cloud, automatisation vers `epiverse-epitech/epiverse`.

Dans ce laboratoire mono-utilisateur, la revue par un autre membre ne peut pas être prouvée sans l'inviter explicitement. Ne pas activer une règle bloquant toutes les PR sans relecteur disponible.
