# Politique de sécurité — LAB public GitHub

**Ce dépôt est PUBLIC intentionnellement et contient uniquement des scénarios fictifs.**

- Ne jamais publier de secrets, tokens, clés SSH, fichiers `.env`, données personnelles de collaborateurs ou documents internes.
- Les Issues, PR, Discussions, Wiki, logs et Pages sont potentiellement publics. Le Project privé n'en masque pas les sources.
- GitHub CodeQL, Dependabot, Secret Scanning et Push Protection sont actifs, mais ne garantissent pas l'absence de données sensibles.
- Les workflows ne disposent de droits d'écriture que lorsqu'une démonstration explicitement demandée l'exige.
- Aucun transfert automatique vers le dépôt officiel EpiVerse, aucun déploiement de production.
- Pour une vulnérabilité, utiliser le **Private vulnerability reporting** du dépôt plutôt qu'une Issue publique.
- Un secret exposé doit être révoqué et remplacé immédiatement, y compris si le commit est supprimé ensuite.

Les anciennes révisions publiques ont pu contenir des noms de personnes réelles. Voir `docs/security/PUBLIC_HISTORY_REVIEW.md` : une correction sur la dernière branche ne purge pas l'historique.
